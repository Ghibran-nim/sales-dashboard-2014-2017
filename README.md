# 📊 Dashboard Analysis of Sales 2014-2017

Proyek ini menyajikan visualisasi dan analisis data penjualan selama periode **2014 hingga 2017**. Dashboard ini dirancang untuk memberikan gambaran menyeluruh mengenai performa penjualan, tren kuartalan, kontribusi segmen pelanggan, serta persebaran geografis penjualan.

## 🛠️ Tools yang Digunakan

* **Google Data Studio / Looker Studio**: Digunakan untuk pembuatan visualisasi data interaktif, pengolahan *card metrics*, *donut chart*, *line chart*, *geo map*, serta *detailed data table*.
* **Dataset**: `Sales Data - DATA.csv`

---

## 📋 Ringkasan & Keterangan Dashboard

Dashboard ini mencakup beberapa indikator utama (KPI) serta komponen visualisasi:

### 1. Key Performance Indicators (KPIs)
* **Total Quantity**: 37.9K produk terjual.
* **Total Sales**: $2.30 Miliar total nilai penjualan.
* **Total Profit**: $286.40 Ribu total keuntungan.

### 2. Komponen Visualisasi
1. **Trend of Sales per Quarter (Line Chart)**:
   * Menampilkan tren pertumbuhan nilai penjualan dari **Q1 2014 hingga Q4 2017**.
   * Terlihat adanya peningkatan tren penjualan secara berkala, dengan puncaknya terjadi pada kuartal akhir (Q4 2017).

2. **Total Sales by Segment (Donut Chart)**:
   * **Consumer**: Menyumbang porsi terbesar yaitu **50.6%**.
   * **Corporate**: Menyumbang porsi kedua sebesar **30.7%**.
   * **Home Office**: Menyumbang porsi sebesar **18.7%**.

3. **Total Sales by State (Geo Map)**:
   * Pemetaan persebaran total penjualan berdasarkan negara bagian di Amerika Serikat.
   * Negara bagian dengan penjualan tertinggi (warna biru lebih tua) berlokasi di area seperti **California** dan **Texas**.

4. **Sales by Data Detailed (Table)**:
   * Tabel terperinci yang mencakup gabungan informasi **Tahun-Kuartal**, **Wilayah (Region)**, dan **Total Sales** terkategori.
